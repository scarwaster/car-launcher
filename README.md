# car-launcher
Overview: A custom automotive launcher designed to transform your car's multimedia display or tablet into a clean, safe, and high-performance interface.
Dashboard Layout
Quick Info Widget: Weather forecast, current temperature, time, date, and connection status.

Media Center: Interactive player card displaying album art, track info, and large playback controls.

Navigation Shortcuts: One-touch access to frequent destinations (Home/Work with real-time traffic), map apps, and voice commands.

Bottom Dock: Quick access drawer for phone, vehicle settings, camera, and the full app menu.

Key Features
Auto Day/Night Mode: Switches between high-contrast daylight visibility and deep dark mode for night driving.

Focus Mode: Hides non-essential notifications, leaving only navigation, media, and a digital speedometer visible.

Smart Boot: Fast initialization upon ignition, automatically launching your preferred media or navigation app.

Visual Identity
Color Palette: Absolute black background with textured dark grey elements and customized accent highlights.

Typography: Clean, geometric fonts designed for quick glances to minimize driving distractions.
